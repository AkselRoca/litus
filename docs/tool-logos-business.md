## Verification and practical notes

- All five SVG files parse as XML and render through Sharp. They contain no scripts, event handlers, `foreignObject`, remote image/font references, or unresolved CSS variables. Meta's gradient references are local to its own SVG.
- Airtable is an original transparent PNG, not a bitmap wrapped in an SVG. Its alpha values span 0–255. Keep its bitmap format. It is suitable for the requested 22–26 CSS pixel slot; vector artwork would offer more detail on high-density screens, but no substitute geometry was invented.
- A contact sheet rendered each final asset at 26 × 26 on white and `#111111`. This caught Notion's original CSS dependency, which was resolved using the vendor's actual black value before final delivery.
- The Meta company logo ZIP failed to download; the selected infinity mark is instead the SVG served directly by Meta's current website. Make's public ZIP endpoints returned HTTP 403, so the original compact mark was extracted from its official documentation SVG. Notion's media kit ZIP link returned 404, so the current website's own inline vector was used.
- These files document provenance, not affiliation or a transfer of trademark rights. Brand owners retain their marks; retain appropriate clear space and avoid presenting the tools row as a partner certification.
