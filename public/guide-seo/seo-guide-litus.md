## 1. Résumé exécutif & insights clés

### Volumes de recherche — Ce qu'il faut retenir

**Marché géolocalisé (notre cible prioritaire) :**
- **Lorient/Morbihan** : ~90 mots-clés actifs, ~1 870 recherches/mois cumulées
- **Le Mans/Sarthe** : ~37 mots-clés actifs, ~770 recherches/mois cumulées
- **Total marché local adressable : ~2 640 recherches/mois**

**Top mots-clés géolocalisés (volume mensuel) :**
- agence web vannes : 260/mois (notre plus gros mot-clé local)
- agence web le mans : 210/mois
- agence web lorient : 110/mois
- création site internet vannes : 110/mois
- agence seo vannes : 110/mois
- consultant seo le mans : 110/mois
- agence seo lorient : 70/mois

**Concurrence :**
- La concurrence est majoritairement **Faible** sur les mots-clés géolocalisés → opportunité majeure
- Les mots-clés nationaux "création site internet" sont **Élevé** → se battre via le local, pas le national
- CPC Google Ads entre 1€ et 7€ sur le local → référence pour estimer la valeur SEO

### Décisions stratégiques clés

1. **Priorité absolue aux pages locales** : la concurrence est faible, les volumes sont là, et c'est notre marché. Chaque ville importante doit avoir sa page dédiée.
2. **Vannes est le plus gros marché Morbihan** : plus de volume que Lorient sur presque tous les services. Traiter Vannes comme une zone prioritaire au même titre que Lorient.
3. **Le SEO et la création de site sont les 2 piliers** : ils représentent 80%+ du volume local. Google Ads est un service à pousser via le contenu éducatif (les gens ne cherchent pas "agence google ads" autant).
4. **Le blog doit cibler la longue traîne informationnelle** : "comment apparaître sur Google", "prix site internet", "comment faire de la pub sur Google" → ces requêtes attirent nos prospects au stade recherche.
5. **E-commerce et dev sur mesure** : volumes plus faibles mais CPC élevés → prospects à forte valeur. Créer des pages service dédiées même si le volume semble modeste.

### Règle de mapping mots-clés → pages

- **1 page = 1 intention de recherche principale** + mots-clés secondaires/synonymes
- **Pages locales** : mot-clé principal = "[service] + [ville]", secondaires = variantes (création site internet [ville], création site web [ville], etc.)
- **Pages service** : mot-clé principal national, contenu optimisé pour la thématique globale
- **Blog** : 1 article = 1 mot-clé longue traîne informationnel ou transactionnel secondaire
- **Jamais de cannibalisation** : un même mot-clé ne doit pas être ciblé par 2 pages différentes

## 9. Directives techniques SEO

### Balises title et meta description

**Pattern pour les pages locales :**
- Title : `[Service] à [Ville] — Litus Agency | [Département]`
- Meta : `[Service] à [Ville] par Litus Agency. [Proposition de valeur courte]. Devis gratuit.`
- Exemple : `Agence web à Vannes — Litus Agency | Morbihan` / `Création de site internet à Vannes par Litus Agency. Sites vitrines et e-commerce sur mesure pour artisans et PME. Devis gratuit.`

**Pattern pour les pages service :**
- Title : `[Service] — Litus Agency | Agence web Lorient & Le Mans`
- Meta : description du service + bénéfice client + CTA

**Pattern pour les articles blog :**
- Title : `[Titre accrocheur avec mot-clé] | Blog Litus Agency`
- Meta : résumé de l'article + incitation à lire

### Structure Hn

```
H1 : Un seul par page, contient le mot-clé principal (naturellement formulé)
  H2 : Sections principales (3-6 par page)
    H3 : Sous-sections si nécessaire
```

### Schema.org (JSON-LD)

**Pages locales :** `LocalBusiness` ou `ProfessionalService`
```json
{
  "@context": "https://schema.org",
  "@type": "ProfessionalService",
  "name": "Litus Agency — [Ville]",
  "description": "[Service] à [Ville]",
  "url": "https://www.litus-agency.fr/[slug]",
  "areaServed": { "@type": "City", "name": "[Ville]" },
  "address": { "@type": "PostalAddress", "addressLocality": "[Ville]", "addressRegion": "[Département]" },
  "serviceType": ["Création de site internet", "SEO", "Google Ads"]
}
```

**Articles blog :** `Article` avec `author`, `datePublished`, `dateModified`

**Homepage :** `Organization` avec `areaServed` listant les 2 zones

### Open Graph & réseaux sociaux

Chaque page doit avoir : `og:title`, `og:description`, `og:image` (image de couverture unique par page), `og:url`, `og:type`.

### Sitemap & robots.txt

- Sitemap XML avec toutes les pages indexables
- Priorités : homepage 1.0, pages service 0.9, pages locales principales (Vannes, Lorient, Le Mans) 0.8, autres pages locales 0.7, blog 0.6
- Robots.txt : bloquer les pages utilitaires (mentions légales, CGV, etc.) si non pertinentes

### Performance web

- Core Web Vitals : LCP < 2.5s, FID < 100ms, CLS < 0.1
- Images : WebP/AVIF, lazy loading, dimensions explicites
- Astro : tirer parti du SSG pour des pages statiques ultra-rapides

## 10. Annexe — Méthodologie et notes

### Source des données
- **Outil :** Google Keyword Planner (campagne Google Ads active, compte MCC 745-799-1176)
- **Période :** Mars 2025 — Février 2026
- **Localisation :** France entière (les volumes incluent toutes les recherches nationales, les mots-clés géolocalisés filtrent naturellement par la requête elle-même)
- **Nombre initial de mots-clés collectés :** ~6 000 (incluant les suggestions automatiques de Google)
- **Après déduplication et nettoyage :** ~3 000 mots-clés avec volume >= 10

### Limites
- Google Keyword Planner arrondit les volumes (10, 20, 30, 50, 70, 90, 110, etc.) — les chiffres sont des estimations
- Les volumes locaux (ville + service) sont probablement sous-estimés car beaucoup de variantes ont 0-10 recherches individuellement mais constituent un volume cumulé non négligeable
- Les mots-clés sans volume affiché (< 10/mois) ne sont pas inclus dans les tableaux mais peuvent être ciblés en longue traîne dans le contenu

### Légende des colonnes
- **Vol/mois** : Moyenne des recherches mensuelles sur les 12 derniers mois
- **Concurrence** : Niveau de concurrence publicitaire (Google Ads) — Faible / Moyen / Élevé / Inconnu
- **Index** : Score de concurrence de 0 à 100
- **CPC bas / CPC haut** : Fourchette d'enchère Google Ads pour apparaître en haut de page (en euros)
- **Service** : Catégorie de service associée au mot-clé

### Catégories de service utilisées
- `creation_site` : création, refonte, agence web, webmaster, site vitrine
- `seo` : référencement naturel, SEO, audit, consultant SEO
- `google_ads` : Google Ads, SEA, publicité Google
- `ecommerce` : boutique en ligne, e-commerce, Prestashop, WooCommerce
- `dev_sur_mesure` : application web, outil métier, développement sur mesure
- `intention_prix` : prix, tarif, combien coûte, devis, budget
- `intention_info` : comment, pourquoi, guide, tuto
